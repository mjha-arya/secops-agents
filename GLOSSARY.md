# Agent Glossary

- **agentC** — Builds and extends the certificate-expiry notification automation (Defender TVM, Key Vault certs, Entra app secrets, App Gateway/App Service TLS bindings); designs and writes IaC for a human to deploy, never deploys itself.
- **agentD** — Investigates Microsoft Defender XDR alerts/incidents via a read-only Graph MCP server and writes findings reports; investigate-only, no write/shell/remediation capability.
- **agentNolan** — Product manager: turns `program\objective.md` into a PRD with users, outcomes, testable acceptance criteria and release slices (`/grilling`, `tech-pdp-spec-writer`, `general-reasoning-council`); files stories as GitHub issues behind a y/N gate. No shell, no code.
- **agentPradyuman** — Program manager: turns the PRD into `program\roadmap.md` (milestones = blueprint phases with their gates), GitHub milestones/issues/project, a `/project-artifact` status page and a blockers-first `program\status.md`; writes the hand-off packets to Daya and Dino. Gates are evidence, not dates. No shell, no code.
- **agentDaya** — Technical lead/architect of the DSPM (`dspm\`, Databricks-first): writes the spec and ADR per component (`/feature-dev`) and is the review gate for Dino's builds (`/code-review`, `/review-pr`, `security-guidance`). Also the read-only operator of the Databricks Control Tool (the DSPM's posture layer) via a local MCP server; drafts registry/exception/inventory proposals for a human to ratify. Gated shell; never pushes, applies, promotes or edits the registry.
- **agentDino** — Developer: implements Daya's specs as tested Python under `dspm\`, one issue at a time (`/tdd`, `/codebase-design`, `context7` docs, `/code-review`, `/commit`), under a y/N-gated shell; hands back to Daya for review. Never pushes, never touches ADRs or the control tool's registry.
- **agentCID** — Inspector of agents: scores any agent folder in this repo — deterministically via `inspectAgents.py` (structure, guardrails wired, memory integrity, skill references resolve, secrets, imports) and qualitatively against `knowledge\agentRubric.md` (do the guardrails match the soul's "never"s, is judgement separated from mechanics, is the readme honest). Uses `agent-sdk-verifier-py`, `/code-review`, `/review-pr`, `claude-md-management`, `contoso-skill-reviewer`. Writes reports only; never edits another agent.
- **mcpServerCreator** — Designs and builds read-only MCP servers for SecOps tooling (Purview, then Defender).
